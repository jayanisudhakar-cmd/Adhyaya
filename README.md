# Namma Guru (Adhyaya)

An AI-powered, multilingual, and adaptive personalized learning platform designed to bridge the education gap in rural areas and provide accessible education for neurodivergent learners.

##  Features

* **Hyper-Personalized AI Tutor:** Dynamic platform generating localized, real-time curriculum based on user inputs.
* **Culturally Relevant Teacher Avatars:** Generates avatars from user-uploaded faces, dressed in traditional Indian attire (Saree/Dhoti).
* **Multilingual Voice & Text:** Translates and vocalizes complex concepts into regional Indian languages (Hindi, Tamil, etc.).
* **Neurodivergent Support:** Custom pacing, low-sensory adjustments, and alternative pedagogical strategies for students with diverse learning needs.
* **Adaptive Complexity:** Adjusts analogies (e.g., using rural/village concepts) and teaching pace according to student requirements.

## 🛠️ Tech Stack

* **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, Firebase
* **Backend / LLM Integration:** OpenAI GPT-4o-mini, GPT-4 (Vision), DALL-E 3, D-ID API
* **Development Environment:** VS Code, Streamlit / Web UI
